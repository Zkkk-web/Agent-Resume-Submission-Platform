# 产品动画分镜

| 时间 | 画面 | 用户看到的价值 | 转场 |
|---|---|---|---|
| 0–2s | 用户上传简历并说一句“帮我找适合的 AI 产品岗位” | 一句话启动，不需要学习复杂 Prompt | 输入框上移，档案面板出现 |
| 2–4s | 从简历建立长期职业档案，补齐成果与个人贡献 | Agent 先真正了解候选人 | 档案卡缩小进入流程列 |
| 4–6s | 同时搜索泛函、Bonjour、Watcha，整理岗位并去重 | 多来源统一找岗，不是只改简历 | 来源卡汇聚成岗位列表 |
| 6–8s | 选择岗位后，围绕 JD 追问一个关键问题 | 只问最能提高面试机会的问题 | 问题答案进入简历卡 |
| 8–10s | 生成可编辑 HTML 简历，用户确认后辅助申请 | 结果可检查、可修改，最终提交由用户完成 | 收束到产品名与安装提示 |
